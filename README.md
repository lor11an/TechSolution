## 🚀 Quick Start

### Option 1: Direct Open
Simply open `index.html` in any modern browser:
```bash
# On Linux/Mac
xdg-open index.html      # Linux
open index.html          # Mac

# On Windows
start index.html
```

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python3 -m http.server 8000

# Using Node.js (npx)
npx serve .

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000`

### Option 3: VS Code Live Server
1. Install "Live Server" extension
2. Right-click `index.html`
3. Select "Open with Live Server"

## 🌐 Deployment

### Deploy to Vercel
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

### Deploy to Netlify
```bash
# Drag & drop the workspace folder to netlify.com
# Or use Netlify CLI
npm i -g netlify-cli
netlify deploy --prod
```

### Deploy to GitHub Pages
```bash
# Create a new branch or use main
git add .
git commit -m "Deploy Tech Solution website"
git push origin main
# Enable GitHub Pages in repository settings
```

## 🔧 Customization

### Change Brand Colors
Edit CSS custom properties in the `:root` selector:
```css
:root {
  --blue-core:  #2563EB;    /* Primary blue */
  --cyan-core:  #06B6D4;    /* Accent cyan */
  --bg-void:    #0B0F19;    /* Background */
}
```

### Update Company Info
Search and replace in `index.html`:
- Company name: "Tech Solution"
- Tagline: "Building The Future Through Technology"
- Contact information in footer and contact section

### Modify Services
Locate the services section (around line 1805) and edit service cards.
